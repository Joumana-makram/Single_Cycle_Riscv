# Single_Cycle_Riscv
Single-Cycle RISC-V Processor
A 32-bit single-cycle RISC-V processor implemented in Verilog. The design includes the main datapath components such as the program counter, instruction memory, register file, immediate generator, control unit, ALU, data memory, multiplexers, and branch logic.
A basic testbench is included to simulate and verify processor behavior.
Features
32-bit single-cycle RISC-V architecture
Program Counter (PC)
Instruction Memory
32 × 32-bit Register File 
Immediate Generator
Main Control Unit
ALU Control
ALU with:
ADD
SUB
AND
OR
Data Memory
Load/Store support
BEQ branch support
Basic SystemVerilog testbench
